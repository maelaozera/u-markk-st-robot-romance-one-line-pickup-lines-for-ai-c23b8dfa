## The entry

A single-line pickup line spoken directly to an AI: the speaker asks the model itself for the perfect pickup line, and the model answers by printing its own name — the machine premise is the punchline, no worn battery/charging/reboot move in sight.

## How to run

Requires Node 22 or later. From the repository root:

```sh
node main.ts
```

This writes the pickup line to `/output/entry.txt` (1–200 characters, single line, self-checked by the program before writing).
